SARI-SARI SMART (ANDROID) — MAIN TUTORIAL (14 STEPS)
====================================================
Config: NavGraph.kt -> val tutorialSteps
Type: multi-page full-flow tutorial
Pages: morning -> day -> closing -> inventory -> debts -> settings
Launch: auto on fresh app launch (Morning LaunchedEffect); Settings ->
  Tutorial selector -> Main Tutorial; Help -> "Replay Tutorial"; all manual
  launches route through startPageTutorial("main") -> startTutorial(replay=true)
  (web v2.40 parity — behaves identically to the auto-launch).

SHARED STEP FIELDS
- Highlight: pure outline — white 2dp inner ring + green 4dp outer ring,
  transparent center, follows registered bounds (tutorialHighlight modifier)
- Box position rule: no target -> bottom; target in top 45% -> bottom; else top
- Auto-scroll: animates scroll so the target is visible before showing the step
- Navigation: Next advances; last step becomes Finish; Skip on replay only;
  backdrop tap (replay) dismisses in place; no Previous
- Completion: after the FINAL step the app returns to the MORNING page
  (web v2.40 parity fix)
