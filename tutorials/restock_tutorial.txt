SARI-SARI SMART (ANDROID) — RESTOCK TUTORIAL (8 STEPS)
======================================================
Config: TutorialOverlay.kt -> pageTutorials ("restock", prefix "restockTutorial")
Page: restock (all steps)
Launch: Restock Day page -> Tutorial selector / Help selector (startPageTutorial("restock"))

NOTE ON TRANSLATION: The `restockTutorial1..8` keys exist ONLY in the English
(en) dictionary of Strings.kt — there is NO Filipino (fil) translation. When
the app language is Filipino, the `get()` helper falls back to English
(dict[key] ?: en[key] ?: key). All 8 steps therefore show the English text
below in both languages. This matches the web app's documented behavior.

NOTE ON HIGHLIGHTS: Android page tutorials generate steps with NO highlight
targets, so the box stays at bottom center and no highlight frame is drawn.
