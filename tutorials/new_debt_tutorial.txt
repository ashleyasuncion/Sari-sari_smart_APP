SARI-SARI SMART (ANDROID) — NEW DEBT TUTORIAL (4 STEPS)
=======================================================
Config: TutorialOverlay.kt -> pageTutorials ("newDebt", prefix "newDebtTutorial")
Page: new_debt (all steps)
Launch: New Debt page -> Tutorial selector / Help selector (startPageTutorial("newDebt"))

NOTE: Android page tutorials generate steps with NO highlight targets, so
the box stays at bottom center and no highlight frame is drawn.

STEP 1 — New Debt intro
  Key      : newDebtTutorial1
  Text EN : "This page lets you manually record a new debt for a customer."
  Text FIL: "Ang page na ito ay para manu-manong magtala ng bagong utang para sa isang kostumer."
  Interaction : read text, tap Next
STEP 2 — Customer name
  Key      : newDebtTutorial2
  Text EN : "Enter the customer's name. If they're a new customer, they'll be added automatically."
  Text FIL: "Ilagay ang pangalan ng kostumer. Kung sila ay bagong kostumer, awtomatiko silang idadagdag."
  Interaction : look at the name field, tap Next
STEP 3 — Debt amount
  Key      : newDebtTutorial3
  Text EN : "Enter the debt amount. This will be added to the customer's existing balance."
  Text FIL: "Ilagay ang halaga ng utang. Ito ay idadagdag sa existing balance ng kostumer."
  Interaction : look at the amount field, tap Next
STEP 4 — Save Debt
  Key      : newDebtTutorial4
  Text EN : "Tap \"Save Debt\" to record it. You can view all debts on the Utang page."
  Text FIL: "I-tap \"Save Debt\" para itala ito. Maaari mong tingnan ang lahat ng utang sa Utang page."
  Interaction : read text, tap Finish (page tutorial finishes in place)
